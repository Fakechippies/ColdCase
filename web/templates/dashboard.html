Security posture

  • Bound to the loopback interface by default.
  • Tool names are validated against the catalog; arguments are passed as arrays — never through a shell.
  • All state-changing requests require a CSRF token.
  • Root-needing tools require explicit confirmation before execution.
  • Tools run through the same runner as the CLI, so session audit logging is preserved.
